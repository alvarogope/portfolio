## Content structure

Before adding, moving, or duplicating any content across the portfolio, consult
[docs/section-ownership-map.md](docs/section-ownership-map.md). Each idea/section has ONE canonical
owner. When content repeats, prefer ABSORBING it into the relevant visual component (per the map)
over leaving duplicate prose. Update the map when a section's ownership changes.

An absorb moves **keys, not copy**: the component reads ids and renders names plus links, so the
owning section stays the only place a thing is described.
